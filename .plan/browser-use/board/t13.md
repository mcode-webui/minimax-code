## Parent

#176 — WebUI Browser Use specification

## What to build

The Agent's browser tools work against the person's own browser. A command the Agent issues is
routed over the bridge to the extension, applied to the tab that run selected, and the result comes
back the same way it would from the isolated browser.

While Full CDP access is off, only the restricted command set crosses the bridge. With it on, every
command that particular browser actually supports may cross, and a command that browser does not
support is reported as unsupported.

## Acceptance criteria

- [ ] A browser-core operation is routed to the extension connection that matches the requested
      browser and the run-scoped target.
- [ ] The operation executes against the tab the run selected, and the result reports that tab.
- [ ] While Full CDP access is off, only the restricted command set is routed. With it on, every
      command the browser actually supports is routed.
- [ ] A method the browser does not support is reported faithfully as unsupported, naming the
      method, and is never substituted with a different command.
- [ ] The command set a client may request is a bounded, named set. A client cannot name an
      arbitrary provider method and have it executed.
- [ ] A command for a browser that is not connected or not authorized fails with a stable error.
- [ ] The routing is proven with a synthetic extension peer for a successful command, an unsupported
      command, a wrong-browser command and a wrong-target command.
