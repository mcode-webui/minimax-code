## Parent

#176 — WebUI Browser Use specification

## What to build

A Browser panel in the workspace that shows the page the Agent is working on, as a live image
stream, and that follows the target of the Agent run the person is looking at.

The panel is a picture of a browser, not a browser: it never embeds the target site, so it works
for any site the Agent visits, including sites that refuse to be framed. The local-HTML preview
that already exists is not a control surface and is not repurposed as one.

## Acceptance criteria

- [ ] A Browser panel exists in the workspace panel composition and renders the live image stream of
      the selected target.
- [ ] The panel does not embed the target origin in an iframe, and the existing local-HTML preview
      surface is not reused as a browser control surface.
- [ ] The page shown in the panel is the same page the provider reports as the active target.
- [ ] The panel follows the active or focused Agent run: when that run selects a different authorized
      target, the panel updates to it, and it does not overwrite another run's selection.
- [ ] The panel renders explicit, user-readable states for: loading, browser not enabled, no tabs,
      pairing required, reconnecting, target closed, stream failed, and permission required.
- [ ] The panel is a consumer of the browser business's published contracts and owns no browser
      state.
- [ ] The panel applies the WebUI's existing design tokens and keyboard and focus conventions.
- [ ] The panel is covered by the WebUI's own client test conventions — transitions extracted into
      pure functions, render branches asserted through static markup rendering — with no new DOM
      test framework.

## Source

- ADR 0019 — the panel shows the browser through a live image stream and forwards user input; it is
  not an iframe into the target site; the panel follows the active run's target.
- Plan — WP4, "Build the Browser workspace panel and Settings controls".
- Research notes — #174 browser-core contracts and client conventions (the panel composition, the
  inert HTML preview, the client business layout to mirror).
