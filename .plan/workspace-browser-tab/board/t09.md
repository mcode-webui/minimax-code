## Parent

199 — workspace browser tab model specification

## What to build

The strip renders web tabs, and the browser tool tab is deleted.

The strip is a new component, `WebuiWorkspaceTabStrip`, in
`packages/webui/src/client/features/workspace/ui/` (the bindings layer).
`WorkspacePanels.tsx` is already 59kb and the strip, the launcher and the toolbar are one more
piece in it; they are one piece of work, and they are not the same piece as the file tree or the
diff.

A web tab shows the page's **title** — the one the provider already reports for the target — and a
**default glyph**. Fetching a site's icon is a separate piece of work and is not part of this.

The browser tool tab is **deleted**, not kept alongside. Its picture and its input are a web tab's,
its target list is the strip's tabs, and the surface switcher it carried
(`packages/webui/src/client/features/browser/ui/BrowserPanel.public.tsx:207`) has no surface left to
switch between: the embedded panel is the isolated browser's view, and the external browsers are
driven in the user's own windows.

The browser business's two published components keep their names — `BrowserPanelHost.public.tsx`
and `BrowserPanel.public.tsx` — because a rename would break the Desktop fork's imports and would
show up as a conflict at the next source synchronisation. What they now *are* is a web tab's host
and its content, and that is recorded in ADR 0022 and in the browser-use documents.

## Acceptance criteria

- [ ] The strip renders tool tabs and web tabs in one row, and the browser tool tab is gone.
- [ ] A web tab shows the page's title, and it updates when the page navigates.
- [ ] A web tab shows a default glyph; no favicon is fetched.
- [ ] The surface switcher is gone from the interface, and the external browsers are not reachable
      from the panel.
- [ ] A new source path is recorded in the frozen path metadata fixture, and the source inventory
      is regenerated.
- [ ] The two published browser components are still published under their existing names, and
      what they now are is stated in the browser-use documents.
- [ ] The strip's tab strip follows a browser's rules: a new tab opens with the new tab page, a tab
      can be closed, and one tab is active at a time.
