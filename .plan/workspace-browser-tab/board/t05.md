## Parent

199 — workspace browser tab model specification

## What to build

The image stream becomes **per target**.

`watchBrowserFrames` takes `{ surface, runId? }` today
(`packages/webui/src/shared/operation-names.ts:458-461`), and the service resolves the run's
selection to decide what to stream
(`packages/webui/src/runtime/browser/browser-service.ts:588`, `:655`). That is what makes the
person and the Agent share one page — and it is also what stops a person from looking at a second
page.

The stream is therefore keyed by the **target** instead of the run: the client asks for the target
it is showing, the service's frame subscribers are keyed by target
(`browser-service.ts:180`), and a frame is delivered only to the tab that asked for it.

This is a **change to an existing operation's request shape**, not a second operation beside it. A
client that still sends a run id is asking for the run's selection, and the two must not be
confused: the request shape changes, the operation's name does not, and a client that sends the
old shape is refused rather than quietly answered with the wrong page.

The fence is unchanged: `#frameMatchesSelection` (`browser-service.ts:733`) compares all four
identity fields including the generation, and a frame that does not match is dropped
(`browser-service.ts:664`).

## Acceptance criteria

- [ ] The frame operation's request names a target, and the service streams that target.
- [ ] Two tabs get their own pictures, and neither receives the other's frames.
- [ ] A frame for a target the subscriber did not ask for is dropped, and the drop is visible in
      the evidence.
- [ ] The generation check still decides whether the page behind a frame is the one on screen: a
      frame from a superseded generation is refused on every page.
- [ ] A client that sends the old request shape is refused with an explicit error, rather than
      being answered with the run's selection.
- [ ] The run's selection still decides what the **Agent's** commands act on; the stream's key
      change does not move the command path.
